# The Resonance Cartographer

An AI-assisted conceptual exploration of the information-singularity hypothesis, connecting equation topology, quantum gravity, and integrated information.

The GitHub Pages site is published from the repository root. Source data, Python simulations, and generated visualizations are included in this repository.

## Run the simulations

Create a Python environment with the packages required by the scripts, then run:

```powershell
python build_reverse_time.py
python holographic_ceiling.py
python quantum_hardware.py
python singularity_rewind.py
```

## Research scope

This is exploratory, non-peer-reviewed conceptual work. It is not an established cosmological model.
